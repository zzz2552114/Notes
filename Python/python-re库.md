# Python `re` 库笔记

> 前提：你已掌握 BRE/ERE。本文以「和 BRE/ERE 的差异」为主线，由浅入深。默认环境 Python 3.11+（会标注版本差异）。

---

## 0. 定位：`re` 是什么「方言」

| 维度                   | BRE/ERE（grep/sed/awk） | Python `re`                       |
| ---------------------- | ----------------------- | --------------------------------- |
| 引擎                   | 传统 POSIX 正则         | 回溯引擎，PCRE 风格               |
| `\d \w \s`             | 不原生支持              | 原生支持                          |
| 非贪婪 `*?`            | 不支持                  | 支持                              |
| 环视 `(?=)` `(?<=)`    | 不支持                  | 支持                              |
| 命名分组               | 不支持                  | `(?P<name>...)`                   |
| 反向引用               | BRE 用 `\1`             | `\1` / `\g<1>` / `(?P=name)`      |
| 原子组/占有量词        | 不支持                  | **3.11+** 支持 `(?>...)`、`*+` 等 |
| Unicode                | 依赖 locale             | 默认 Unicode                      |
| `\p{...}` Unicode 属性 | 不支持                  | **不支持**（需第三方 `regex`）    |
| 条件分组 `(?()|)`      | 不支持                  | **不支持**                        |
| 分支重置 `(?|...)`     | 不支持                  | **不支持**                        |
| 递归 `(?R)`            | 不支持                  | **不支持**                        |

**一句话**：`re` 是 BRE/ERE 的超集，但**不是 PCRE 全集**。从 PCRE 迁过来时，`\p{}`、条件分组、分支重置、递归这四样没有。

## 1. 最基础的格式：模式字符串

### 1.1 永远用原始字符串 `r"..."`

```python
import re

# ✅ 推荐
re.search(r"\d+", "abc123")

# ❌ 不推荐：Python 字符串层先转义一次，正则层再转义一次
re.search("\\d+", "abc123")
```

**为什么**：正则用 `\` 做转义，Python 字符串也用 `\` 做转义。写 `"\d"` 时 Python 会先把 `\d` 当未知转义（3.12 起会警告），实际传给 `re` 的可能是 `\d` 也可能是别的。`r"\d"` 保证原样传给 `re`。

**例外**：模式里要匹配字面量反斜杠 `\`，写 `r"\\"`；要匹配换行，写 `r"\n"`（`re` 自己认识 `\n`）。都仍然用 `r` 前缀。

### 1.2 两种「找」：`match` vs `search`

| 函数                 | 起点                 | 语义                       |
| -------------------- | -------------------- | -------------------------- |
| `re.match(p, s)`     | **只在 `s[0]` 尝试** | 必须从开头匹配             |
| `re.fullmatch(p, s)` | 从 `s[0]` 到末尾     | 整串必须完全匹配（3.4+）   |
| `re.search(p, s)`    | 扫描全串             | 找**第一个**匹配，任意位置 |

```python
re.match(r"\d+", "abc123")      # None（开头不是数字）
re.search(r"\d+", "abc123")     # <Match '123'>
re.fullmatch(r"\d+", "123")     # <Match '123'>
re.fullmatch(r"\d+", "123abc")  # None
```

**注意**：`match` 不是「匹配整个字符串」，只是「从开头匹配」。要整串匹配用 `fullmatch` 或 `\A...\Z`。

## 2. 字符匹配基础（和 ERE 共通，快速过）

| 语法     | 含义                          | 备注                    |
| -------- | ----------------------------- | ----------------------- |
| `a`      | 字面量                        |                         |
| `.`      | 任意字符（**默认不含 `\n`**） | 加 `re.S` 才含换行      |
| `[abc]`  | 字符类                        |                         |
| `[^abc]` | 否定字符类                    | `^` 必须在 `[` 后第一位 |
| `[a-z]`  | 范围                          |                         |
| `[]]`    | 匹配 `]`                      | `]` 放第一位是字面量    |
| `[a^]`   | `^` 在非首位是字面量          |                         |

**字符类里的特殊规则**：

- `[.]` 是字面量点，不是「任意字符」；
- `[$^*()+{}\|?]` 里大部分元字符变字面量；
- `[` 里的 `\` 仍然转义：`[\]]`、`[\\]`；
- **BRE/ERE 的 `[[:alpha:]]` POSIX 字符类，Python `re` 不支持**。用 `[a-zA-Z]` 或 `\w`（注意 Unicode）。

## 3. 量词

| 语法                    | 含义                  | ERE 兼容   |
| ----------------------- | --------------------- | ---------- |
| `*`                     | 0 次或多次            | ✅          |
| `+`                     | 1 次或多次            | ✅          |
| `?`                     | 0 或 1 次             | ✅          |
| `{m}`                   | 恰好 m 次             | ✅          |
| `{m,}`                  | 至少 m 次             | ✅          |
| `{m,n}`                 | m 到 n 次             | ✅          |
| `*?` `+?` `??` `{m,n}?` | **非贪婪**            | ❌ ERE 没有 |
| `*+` `++` `?+` `{m,n}+` | **占有量词**（3.11+） | ❌          |

### 3.1 贪婪 vs 非贪婪（重点）

- **贪婪**（默认）：先吃满，再回溯。
- **非贪婪**：先吃最少，再扩展。

```python
s = "<a><b>"
re.search(r"<.*>",  s).group()   # '<a><b>'   贪婪
re.search(r"<.*?>", s).group()   # '<a>'      非贪婪
```

**关键理解**：非贪婪不是「永远最少」，是「**在能让整体匹配成功的前提下最少**」。

```python
re.search(r"<.*?>b>", "<a><b>").group()   # '<a><b>'
```

`<a>` 后面没有 `b>`，非贪婪会继续扩展到 `<a><b>` 才成功。

### 3.2 占有量词（3.11+）

```python
re.search(r"\d++", "123abc").group()   # '123'，吃掉后不回溯
```

`*+` 吃掉所有数字后**不回退**。用于防止回溯爆炸。等价于原子组 `(?>...)`。

**兼容性**：3.11 之前不支持，会当语法错误或匹配 `+` 字面量。写库时慎用。

## 4. 分组

| 语法            | 类型            | 说明                            |
| --------------- | --------------- | ------------------------------- |
| `(...)`         | 捕获组          | 有编号，从 1 开始，按左括号顺序 |
| `(?:...)`       | 非捕获组        | 只分组，不捕获，不占编号        |
| `(?P<name>...)` | 命名捕获组      | 可用 `group("name")` 取         |
| `(?P=name)`     | 反向引用命名组  | 模式内引用                      |
| `\1` `\2`       | 反向引用编号组  | 模式内引用                      |
| `(?>...)`       | 原子组（3.11+） | 吃掉后不回溯                    |

### 4.1 编号规则

按**左括号出现顺序**编号，嵌套时外层是 1，内层是 2：

```python
re.search(r"((a)(b))", "ab").groups()   # ('ab', 'a', 'b')
#  group1=((a)(b))  group2=(a)  group3=(b)
```

`group(0)` 是整个匹配，`group()` 等价 `group(0)`。

### 4.2 非捕获组：性能和编号

```python
r"(?:https?|ftp)://..."   # 不想捕获协议时
```

**为什么用**：

1. 减少不必要的捕获开销；
2. **保持编号干净**——不占用 `\1`、`\2`。

### 4.3 命名分组

```python
m = re.search(r"(?P<year>\d{4})-(?P<month>\d{2})", "2026-10")
m.group("year")      # '2026'
m.groupdict()        # {'year': '2026', 'month': '10'}
```

**为什么**：分组多了以后 `group(3)` 可读性差，改模式时编号容易错位。命名组和编号组**同时存在**，命名组也有编号。

模式内引用命名组：

```python
re.search(r"(?P<q>['\"]).*?(?P=q)", "'abc'")   # 匹配成对引号
```

### 4.4 重复捕获组只保留最后一次

```python
re.search(r"(\d)+", "123").group(1)   # '3'，不是 '123'
re.search(r"(\d)+", "123").group(0)   # '123'
```

要拿到全部，用 `findall` 或改成 `(\d+)`。

### 4.5 Python 不支持的（PCRE 有）

- **分支重置** `(?|...)`：不支持；
- **条件分组** `(?(1)yes|no)`：不支持；
- **递归** `(?R)`：不支持。

遇到这些需求，用第三方 `regex` 库。

## 5. 锚点与边界

| 语法 | 含义                                              | 受 `re.M` 影响     |
| ---- | ------------------------------------------------- | ------------------ |
| `^`  | 字符串开头（`re.M` 下也匹配每行开头）             | ✅                  |
| `$`  | 字符串末尾或末尾换行前（`re.M` 下也匹配每行末尾） | ✅                  |
| `\A` | **绝对**字符串开头                                | ❌ 永远只匹配真开头 |
| `\Z` | **绝对**字符串末尾                                | ❌ 永远只匹配真末尾 |
| `\b` | 单词边界                                          | ❌                  |
| `\B` | 非单词边界                                        | ❌                  |

**要点**：

- `\Z` 在 Python 里是**绝对末尾**，不像 Perl 的 `\Z` 允许末尾换行前。Python 的 `$` 才允许末尾换行前。
- `\b` 是**零宽**的，它检查「当前位置左边和右边是否一个是 `\w` 一个不是」。
- Unicode 下 `\w` 包含中文，所以 `\b中文\b` 的中文两边是**非** `\w` 才算边界。

```python
re.search(r"\bcat\b", "a cat.")    # 匹配
re.search(r"\bcat\b", "scatter")   # None
```

## 6. 简写字符类（ERE 没有，重点）

| 语法 | 含义（Unicode 默认）                             | ASCII 模式（`re.A`） |
| ---- | ------------------------------------------------ | -------------------- |
| `\d` | Unicode 十进制数字（含全角、阿拉伯-印度数字）    | `[0-9]`              |
| `\D` | 非 `\d`                                          |                      |
| `\w` | Unicode 单词字符（字母、数字、下划线、**汉字**） | `[a-zA-Z0-9_]`       |
| `\W` | 非 `\w`                                          |                      |
| `\s` | Unicode 空白（空格、`\t\n\r\f\v`、全角空格等）   | `[ \t\n\r\f\v]`      |
| `\S` | 非 `\s`                                          |                      |

**在字符类内部也能用**：`[\d\s]` 合法。

**陷阱**：`\w` 默认匹配汉字。

```python
re.search(r"\w+", "你好abc").group()   # '你好abc'
re.findall(r"\w+", "你好abc")          # ['你好abc']
```

只想匹配 ASCII 字母数字下划线，加 `re.ASCII` 或 `(?a)`：

```python
re.findall(r"\w+", "你好abc", re.ASCII)   # ['abc']
```

## 7. 转义与反向引用

### 7.1 模式内的转义

| 写法                                                         | 含义                                                       |
| ------------------------------------------------------------ | ---------------------------------------------------------- |
| `\.` `\*` `\+` `\?` `\(` `\)` `\[` `\]` `\{` `\}` `\|` `\^` `\$` `\\` | 字面量元字符                                               |
| `\n` `\t` `\r` `\f` `\v`                                     | 控制字符                                                   |
| `\x41`                                                       | 十六进制                                                   |
| `\u4e2d`                                                     | Unicode 码点（4 位）                                       |
| `\U0001F600`                                                 | Unicode 码点（8 位）                                       |
| `\N{name}`                                                   | Unicode 名称（如 `\N{BULLET}`）                            |
| `\1` `\2` …                                                  | 反向引用编号组（**模式内**）                               |
| `\g<name>`                                                   | 反向引用命名组，**只在替换模板里用**，模式内用 `(?P=name)` |

### 7.2 数字反向引用的歧义

```python
r"(\d)\10"    # 是 group(10) 还是 group(1) 后跟 '0'？
```

Python 的规则：**优先取最长的合法组号**。如果只有 1 个组，`\10` 会被解释为 group(1) + `'0'`（因为 group(10) 不存在）。有 10 个以上组时会歧义。

**建议**：组多了用命名组 `(?P<n>...)` + `(?P=n)`，或替换里用 `\g<1>0` 明确边界。

## 8. 环视（Lookaround）——零宽断言

### 8.1 四种

| 语法       | 名称     | 含义                   |
| ---------- | -------- | ---------------------- |
| `(?=...)`  | 正向前瞻 | 后面必须能匹配 `...`   |
| `(?!...)`  | 负向前瞻 | 后面必须不能匹配 `...` |
| `(?<=...)` | 正向后顾 | 前面必须能匹配 `...`   |
| `(?<!...)` | 负向后顾 | 前面必须不能匹配 `...` |

### 8.2 零宽是什么意思

断言**只检查，不消耗字符**。匹配成功后位置不动，断言里的内容不进 `group(0)`。

```python
re.search(r"\d+(?=元)", "100元").group()   # '100'，'元' 不在结果里
re.search(r"(?<=\$)\d+", "$100").group()   # '100'，'$' 不在结果里
```

### 8.3 后顾必须定长

Python 要求 `(?<=...)` 和 `(?<!...)` 里的模式**长度固定**：

```python
r"(?<=ab)c"        # ✅ 定长 2
r"(?<=a|bc)d"      # ✅ 每个分支定长（Python 允许不同分支不同长度）
r"(?<=a+)b"        # ❌ error: look-behind requires fixed-width pattern
r"(?<=\d{3})x"     # ✅ 定长 3
r"(?<=\d{3,})x"    # ❌ 变长
```

前瞻没有这个限制（因为向前看不需要知道长度）。

### 8.4 典型用法

```python
# 密码：至少 8 位，含数字和字母（用前瞻做「同时满足」）
r"^(?=.*\d)(?=.*[A-Za-z]).{8,}$"

# 提取 key: value 中 value，但 key 不计入结果
r"(?<=name:\s*)\w+"

# 匹配不被引号包围的单词（简化）
r"(?<![\"'])\bword\b(?![\"'])"
```

### 8.5 性能注意

断言内部如果很复杂，会在每个位置尝试。大量断言 + 回溯可能慢。能写成普通匹配 + 分组就别滥用断言。

## 9. 内联标志（模式内部开关）

写在模式开头（或分组开头）：

| 内联   | 等价 flag | 作用                         |
| ------ | --------- | ---------------------------- |
| `(?i)` | `re.I`    | 忽略大小写                   |
| `(?m)` | `re.M`    | 多行，`^ $` 匹配行首行尾     |
| `(?s)` | `re.S`    | `.` 匹配换行                 |
| `(?x)` | `re.X`    | verbose，忽略空白和 `#` 注释 |
| `(?a)` | `re.A`    | ASCII 模式                   |
| `(?u)` | `re.U`    | Unicode 模式（默认）         |
| `(?L)` | `re.L`    | locale（bytes 模式，少用）   |

**局部作用域**：`(?i:...)` 只在这个组里生效。

```python
re.search(r"(?i:abc)def", "ABCdef")   # 匹配，abc 忽略大小写，def 不忽略
re.search(r"(?i)abc", "ABC")           # 整个模式忽略大小写
```

**组合**：`(?is)` = `(?i)` + `(?s)`。

**注意**：内联 `(?i)` 必须放在模式**最前面**（或分组最前面），否则 Python 3.11+ 会报 `global flags not at the start of the expression`。

## 10. 编译标志 `flags`

| 标志            | 缩写   | 作用                                 |
| --------------- | ------ | ------------------------------------ |
| `re.IGNORECASE` | `re.I` | 忽略大小写                           |
| `re.MULTILINE`  | `re.M` | `^ $` 匹配每行                       |
| `re.DOTALL`     | `re.S` | `.` 匹配 `\n`                        |
| `re.VERBOSE`    | `re.X` | 允许空白和 `#` 注释                  |
| `re.ASCII`      | `re.A` | `\w \d \s \b` 仅 ASCII               |
| `re.UNICODE`    | `re.U` | 默认（Python 3 下 str 模式默认开启） |
| `re.LOCALE`     | `re.L` | 仅 bytes 模式，依赖 locale，不推荐   |
| `re.DEBUG`      |        | 打印编译后的字节码，调试用           |
| `re.NOFLAG`     |        | 3.11+，值为 0，表示无标志            |

**组合**：`re.I | re.M | re.S`。

**注意**：

- `re.S` 只影响 `.`，**不影响** `^ $`；
- `re.M` 只影响 `^ $`，**不影响** `.`；
- `re.A` 影响 `\w \W \d \D \s \S \b \B`，也影响 `(?i)` 的大小写折叠范围；
- str 模式默认 `re.U`，不能关闭（`re.A` 是「退化为 ASCII」，不是「关闭 Unicode」）。

## 11. 核心 API

### 11.1 模块级函数一览

| 函数                                  | 返回              | 说明                     |
| ------------------------------------- | ----------------- | ------------------------ |
| `re.match(p, s, flags)`               | `Match \| None`   | 从开头匹配               |
| `re.fullmatch(p, s, flags)`           | `Match \| None`   | 整串匹配                 |
| `re.search(p, s, flags)`              | `Match \| None`   | 找第一个                 |
| `re.findall(p, s, flags)`             | `list`            | 所有匹配（分组行为特殊） |
| `re.finditer(p, s, flags)`            | `Iterator[Match]` | 所有匹配，惰性           |
| `re.sub(p, repl, s, count=0, flags)`  | `str`             | 替换                     |
| `re.subn(p, repl, s, count=0, flags)` | `(str, int)`      | 替换并返回次数           |
| `re.split(p, s, maxsplit=0, flags)`   | `list[str]`       | 分割                     |
| `re.compile(p, flags)`                | `Pattern`         | 预编译                   |
| `re.escape(s)`                        | `str`             | 转义所有特殊字符         |
| `re.purge()`                          | `None`            | 清空内部缓存             |

### 11.2 `re.search` 没有 `pos` 参数

模块级 `re.search(p, s)` **总是从 0 开始**。要指定起点，必须用编译后的 `Pattern.search(s, pos, endpos)`。

```python
pat = re.compile(r"\d+")
m1 = pat.search("a1 b2")          # pos=0，找到 '1'
m2 = pat.search("a1 b2", m1.end())  # pos=2，找到 '2'
```

**重要**：`pos` 不是切片。`\b`、`(?<=...)`、`\A` 仍能看到 `pos` 之前的内容。

```python
pat = re.compile(r"(?<=a)b")
pat.search("ab", 1)   # 匹配 'b'，lookbehind 能看到 pos=1 前的 'a'
"ab"[1:]              # 'b'，但切片方式就看不到 'a'
```

`\A` 仍然只匹配**真开头**，不会把 `pos` 当开头。

### 11.3 Match 对象

```python
m = re.search(r"(?P<y>\d{4})-(?P<m>\d{2})", "2026-10")
```

| 属性/方法                     | 返回          | 说明                   |
| ----------------------------- | ------------- | ---------------------- |
| `m.group()` / `m.group(0)`    | `str`         | 整个匹配               |
| `m.group(1)` / `m.group("y")` | `str`         | 指定组                 |
| `m.group(1, 2)`               | `tuple`       | 多个组                 |
| `m.groups()`                  | `tuple`       | 所有组（不含 0）       |
| `m.groupdict()`               | `dict`        | 所有命名组             |
| `m.start()` / `m.end()`       | `int`         | 整个匹配的起止索引     |
| `m.start(n)` / `m.end(n)`     | `int`         | 指定组的起止           |
| `m.span()`                    | `(int, int)`  | 起止元组               |
| `m.pos` / `m.endpos`          | `int`         | 搜索范围               |
| `m.string`                    | `str`         | 原字符串               |
| `m.re`                        | `Pattern`     | 对应的 Pattern         |
| `m.lastindex`                 | `int \| None` | 最后一个匹配的组号     |
| `m.lastgroup`                 | `str \| None` | 最后一个匹配的命名组名 |
| `m[n]`                        | `str`         | 等价 `m.group(n)`      |

**没匹配的组**返回 `None`：

```python
m = re.search(r"(a)|(b)", "b")
m.group(1)   # None
m.group(2)   # 'b'
```

### 11.4 Pattern 对象

```python
pat = re.compile(r"\d+", re.I)
```

| 方法                               | 说明                   |
| ---------------------------------- | ---------------------- |
| `pat.search(s, pos=0, endpos=len)` | 带位置                 |
| `pat.match(s, pos, endpos)`        | 从 pos 起              |
| `pat.fullmatch(s, pos, endpos)`    | 整串                   |
| `pat.findall(s, pos, endpos)`      | 列表                   |
| `pat.finditer(s, pos, endpos)`     | 迭代器                 |
| `pat.sub(repl, s, count=0)`        | 替换                   |
| `pat.subn(repl, s, count=0)`       | 替换 + 次数            |
| `pat.split(s, maxsplit=0)`         | 分割                   |
| `pat.flags`                        | 编译标志               |
| `pat.groups`                       | 捕获组数量             |
| `pat.groupindex`                   | 命名组名 → 编号的 dict |
| `pat.pattern`                      | 原始模式字符串         |

**缓存**：模块级函数内部有 LRU 缓存（最多 512 个模式）。重复用同一模式时，`re.search` 和预编译性能差不多；但**在循环里**预编译更明确、可读性更好。

### 11.5 `findall` 的分组行为（重点陷阱）

```python
re.findall(r"\d+", "a1 b22 c333")        # ['1', '22', '333']  无分组 → 整匹配
re.findall(r"(\d+)", "a1 b22 c333")      # ['1', '22', '333']  一个分组 → 分组内容
re.findall(r"(\d)(\d)", "12 34")         # [('1','2'), ('3','4')]  多个分组 → 元组列表
re.findall(r"(\d)+", "123")              # ['3']  重复组只留最后一次
```

**规律**：

- 无分组：返回整匹配字符串列表；
- 1 个分组：返回**分组内容**列表（不是整匹配）；
- n 个分组：返回 n 元组列表；
- 有命名组也一样，`findall` 不看名字。

**要整匹配 + 分组信息**，用 `finditer`：

```python
for m in re.finditer(r"(\d+)", "a1 b22"):
    print(m.group(0), m.group(1))
```

### 11.6 `re.sub` 的 repl

`repl` 可以是**字符串模板**或**函数**。

**字符串模板**：

| 写法               | 含义             |
| ------------------ | ---------------- |
| `\1` `\2`          | 编号组           |
| `\g<1>` `\g<name>` | 明确边界的组引用 |
| `\g<0>`            | 整个匹配         |
| `\\`               | 字面量反斜杠     |
| `\n` `\t`          | 控制字符         |

```python
re.sub(r"(\d{4})-(\d{2})", r"\2/\1", "2026-10")     # '10/2026'
re.sub(r"(?P<y>\d{4})", r"\g<y>年", "2026")          # '2026年'
re.sub(r"(\d)", r"\1\1", "ab1")                      # 'ab11'
```

**函数**：参数是 `Match`，返回替换字符串。

```python
def double(m):
    return str(int(m.group()) * 2)

re.sub(r"\d+", double, "a1 b22")   # 'a2 b44'
```

**注意**：

- `repl` 字符串里 `\1` 是组引用，**不是** Python 字符串转义。用 `r"\1"`；
- 组不存在会报 `error: invalid group reference`；
- 函数返回 `None` 会报 `TypeError`，返回非 `str` 也会报错。

### 11.7 `re.split` 的捕获组行为（重点陷阱）

**如果模式里有捕获组，分隔符会保留在结果里**：

```python
re.split(r",", "a,b,c")           # ['a', 'b', 'c']
re.split(r"(,)", "a,b,c")         # ['a', ',', 'b', ',', 'c']  逗号保留了！
re.split(r"(\d)", "a1b2c")        # ['a', '1', 'b', '2', 'c']
```

**为什么**：设计如此，方便保留分隔符。不想要就改成非捕获组 `(?:,)`：

```python
re.split(r"(?:,)", "a,b,c")       # ['a', 'b', 'c']
```

`maxsplit` 限制分割次数，剩余部分整体作为最后一项：

```python
re.split(r",", "a,b,c", maxsplit=1)   # ['a', 'b,c']
```

### 11.8 `re.escape`

把字符串里所有正则特殊字符转义，用于「用户输入当字面量」：

```python
re.escape("a.b*c")    # 'a\\.b\\*c'
re.search(re.escape("a.b"), "xa.by")   # 匹配字面量 'a.b'
```

**典型场景**：拼接用户输入到模式里。

```python
keyword = "a.b"
pattern = rf"\b{re.escape(keyword)}\b"
```

## 12. 空匹配（重点陷阱）

能匹配空串的模式：`.*`、`a*`、`x?`、`(?:)`、`\b` 等。

```python
re.findall(r"a*", "bbb")   # ['', '', '', '']  每个位置一个空匹配
re.findall(r"\d*", "a1")   # ['', '1', '']
```

**`finditer` / `findall` 自动推进**：空匹配后前进 1 位，不会死循环。

**手动循环要自己处理**：

```python
pos = 0
while pos <= len(s):
    m = pat.search(s, pos)
    if not m:
        break
    # 处理 m
    pos = m.end() if m.end() > m.start() else m.end() + 1
```

**替换空匹配**：

```python
re.sub(r"", "-", "abc")   # '-a-b-c-'
```

知道这个行为，别被吓到。

## 13. 性能与回溯

### 13.1 回溯爆炸

嵌套量词 + 长不匹配串 = 指数级回溯：

```python
r"(a+)+b"     # ❌ 对 "aaaaaaaaaaaaaaaaaaaaaa" 极慢
```

**对策**：

1. **具体化**：`a+b` 能解决就别嵌套；
2. **占有量词**（3.11+）：`(a++)+b` 或 `(?>a+)+b`；
3. **原子组**：`(?>...)`；
4. 用 `regex` 库的超时参数。

### 13.2 非贪婪不一定快

非贪婪只是「先少后多」，回溯次数可能更多。`.*?` 在长文本 + 复杂后缀时也会慢。**能具体化就具体化**：

```python
r"[^"]*"      # 比 r".*?" 快且语义更明确
r"[^\n]*"     # 只取一行
```

### 13.3 字符类优于 `.`

`[^"]*` 通常比 `.*?` 快，因为它不跨字符类，回溯空间小。

### 13.4 预编译

```python
PATTERN = re.compile(r"\d+")   # 模块级

def f(s):
    return PATTERN.findall(s)  # 不在循环里 re.compile
```

模块级 `re.findall` 有 512 条缓存，但显式预编译**可读性更好**，也避免缓存被挤掉。

### 13.5 `re.VERBOSE` 写可读正则

```python
pattern = re.compile(r"""
    (?P<year>\d{4})   # 年
    -
    (?P<month>\d{2})  # 月
    -
    (?P<day>\d{2})    # 日
""", re.VERBOSE)
```

`re.X` 下：

- 空白被忽略（包括换行）；
- `#` 到行尾是注释；
- 要匹配字面量空格，用 `[ ]` 或 `\ `（转义空格）；
- `#` 字面量用 `\#` 或 `[#]`。

### 13.6 避免在顶层执行有副作用的代码

```python
# ❌ 导入 ReAct 就触发工具加载，导入顺序不可控
toolmanager.load_tools()

# ✅ 延迟到实例化
class ReActAgent:
    def __init__(self):
        self.toolmanager.load_tools()
```

## 14. 常见模式速查

```python
# 数字
r"\d+"                  # 整数
r"-?\d+(?:\.\d+)?"      # 浮点
r"\d{1,3}(?:,\d{3})*"   # 千分位

# 单词
r"\b\w+\b"              # 单词（Unicode 含汉字）
r"[A-Za-z_]\w*"         # 标识符（ASCII 语义）

# 邮箱（简化，别追求 100% RFC）
r"[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Za-z]{2,}"

# URL（简化）
r"https?://[^\s/$.?#].[^\s]*"

# IPv4（每段 0-255，简化版）
r"(?:\d{1,3}\.){3}\d{1,3}"

# 日期 YYYY-MM-DD
r"(?P<y>\d{4})-(?P<m>\d{2})-(?P<d>\d{2})"

# key: value 提取（value 到行尾）
r"^(?P<key>\w+)\s*:\s*(?P<value>.+)$"   # 配 re.M

# 成对引号
r"(?P<q>['\"]).*?(?P=q)"

# 不要用正则解析 HTML —— 用解析器
```

**HTML 为什么不用正则**：嵌套、属性引号、注释、CDATA 会让正则复杂到无法维护。用 `html.parser`、`lxml`、`BeautifulSoup`。

## 15. 和 BRE/ERE 的差异总表

| 特性                   | BRE               | ERE      | Python re       |
| ---------------------- | ----------------- | -------- | --------------- |
| `+` `?` `\|`           | 需 `\+` `\?` `\|` | 直接写   | 直接写          |
| `()` 分组              | 需 `\(` `\)`      | 直接写   | 直接写          |
| `{}` 量词              | 需 `\{` `\}`      | 直接写   | 直接写          |
| `\d \w \s`             | ❌                 | ❌        | ✅               |
| 非贪婪 `*?`            | ❌                 | ❌        | ✅               |
| 环视                   | ❌                 | ❌        | ✅               |
| 命名分组               | ❌                 | ❌        | ✅               |
| `\b`                   | 部分支持          | 部分支持 | ✅               |
| Unicode                | locale            | locale   | 默认            |
| 占有量词/原子组        | ❌                 | ❌        | 3.11+           |
| `\p{...}`              | ❌                 | ❌        | ❌（需 `regex`） |
| 条件分组/分支重置/递归 | ❌                 | ❌        | ❌               |

## 16. 检查清单：写正则前问自己

1. **用 `r"..."` 了吗？**
2. **`match` / `search` / `fullmatch` 选对了吗？**
3. **`.` 需要跨行吗？** 需要就 `re.S`。
4. **`^ $` 需要按行吗？** 需要就 `re.M`。
5. **`\w \d` 需要 ASCII 语义吗？** 需要就 `re.A`。
6. **用了贪婪 `.*` 吗？** 想想是否该用 `.*?` 或 `[^x]*`。
7. **分组需要捕获吗？** 不需要用 `(?:...)`。
8. **组多了吗？** 用命名组。
9. **`findall` 有分组吗？** 记得返回值会变。
10. **`re.split` 有捕获组吗？** 分隔符会保留。
11. **量词嵌套吗？** 警惕回溯爆炸。
12. **取 `.group()` 前判 `None` 了吗？**
13. **`.strip` 后面有 `()` 吗？**（方法对象 ≠ 返回值）
14. **模式要重复用吗？** 预编译。
15. **解析 HTML/JSON/XML 吗？** 别用正则。

## 17. 一句话总结

> Python `re` = BRE/ERE 的超集 + 非贪婪 + 环视 + 命名组 + Unicode + 占有量词（3.11+）。写的时候记住：`r""` 原始字符串、`search` 找第一个、`match` 只从开头、`findall` 分组会改变返回结构、`re.split` 捕获组会保留分隔符、取 `group` 前判 `None`、量词嵌套防回溯爆炸、HTML 别用正则。和 PCRE 比，缺 `\p{}`、条件分组、分支重置、递归——需要就上 `regex` 库。
