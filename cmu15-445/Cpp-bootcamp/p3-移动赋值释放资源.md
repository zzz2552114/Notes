原代码

```cpp
Handle& operator=(Handle&& other) noexcept{
    if(this != &other){ 
        id = other.id;
        valid = other.valid;
        ++moves;
        other.valid = 0;
    }
    return *this;

```



失败原因在 `Handle::operator=(Handle&& other)`：移动赋值时没有释放 `*this` 原来持有的有效资源，只是直接覆盖了 `id` 和 `valid`，导致旧的 `live` 没有减、`releases` 没有加，所以测试里 `Handle::live` 多了 1。

修复方式：移动赋值时，如果当前对象有效，先释放当前资源，再接管 `other`。

修改后的移动赋值：

```cpp
Handle& operator=(Handle&& other) noexcept {
    if (this != &other) {
        // 先释放当前对象原有资源
        if (valid) {
            valid = false;
            --live;
            ++releases;
        }

        // 再接管 other 的资源
        id = other.id;
        valid = other.valid;
        ++moves;
        other.valid = false;
    }
    return *this;
}
```

- 移动赋值前旧资源被释放：`--live`、`++releases`
- 移动赋值后只保留从 `other` 接管的一个有效资源
- `self_move_assign_is_safe` 仍然由 `if (this != &other)` 保证安全

核心修改就是这一句：**移动赋值前必须先释放自身已有资源。**
