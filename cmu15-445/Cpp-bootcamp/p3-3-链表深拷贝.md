# 模块二：链表深拷贝的实现

## 2.1 为什么链表深拷贝不能直接复制 next 指针

链表节点通常包含 `next` 指针。深拷贝时，指针本身存的是地址，不能直接复制这个地址，否则新对象还是指向原来的资源。正确做法：为指针指向的那个对象新分配一块内存，把原对象的内容复制过去，然后让新对象的指针指向这块新内存。

对于链表，`next` 指针尤其要注意：你不能让新链表的 `next` 还指向原链表的节点，而应该指向新复制出来的下一个节点。

## 2.2 浅拷贝链表的问题

假设：

```cpp
struct Node {
    int val;
    Node* next;
};

Node* head = new Node{1, new Node{2, new Node{3, nullptr}}};
```

原链表：

```text
head -> [1] -> [2] -> [3] -> nullptr
```

如果浅拷贝：

```cpp
Node* newHead = head;   // 只复制了地址
```

结果两个 `head` 指向同一串节点。析构时如果两边都 `delete`，就会重复释放。

## 2.3 深拷贝链表的目标

深拷贝要得到：

```text
原链表：head    -> [1] -> [2] -> [3] -> nullptr

新链表：newHead -> [1'] -> [2'] -> [3'] -> nullptr
```

注意：`[1']`、`[2']`、`[3']` 都是新 `new` 出来的节点，和原节点地址不同，只是 `val` 相同。

## 2.4 迭代写法

```cpp
List3(const List3& other):head(nullptr){
    if(!other.head) return;
    head = new N(other.head->v);
    N* curr = head;
    N* ocurr = other.head->next;
    while(ocurr){
        N* tmp = new N(ocurr->v);
        curr->next = tmp;
        curr = curr->next;
        ocurr = ocurr->next;
    }
    curr->next = nullptr;
}
```

关键点：

- `new Node(cur->val)`：只复制数据，不复制 `next`。
- `tail->next = ...`：手动把新节点接到新链表上。
- 原链表的 `cur->next` 只用来遍历，不用复制它的地址。

## 2.5 递归写法

```cpp
Node* clone(Node* node) {
    if (!node) return nullptr;

    Node* copy = new Node(node->val);   // 只复制数据
    copy->next = clone(node->next);     // 递归复制后面的节点
    return copy;
}
```

但递归有两个问题：

1. 链表很长时会栈溢出。
2. 如果 `new` 抛异常，已经分配的节点可能泄漏。

所以工程上更推荐迭代 + RAII 或智能指针。

## 2.6 带环链表 / 双向链表 / 共享节点

### 带环链表

如果链表有环，简单递归或遍历会无限循环。需要哈希表记录“旧节点 -> 新节点”的映射：

```cpp
Node* cloneList(Node* head) {
    if (!head) return nullptr;

    std::unordered_map<Node*, Node*> mp;
    Node* cur = head;

    // 第一遍：为每个旧节点创建一个新节点
    while (cur) {
        if (mp.count(cur)) break;   // 遇到环，停止
        mp[cur] = new Node(cur->val);
        cur = cur->next;
    }

    // 第二遍：连接 next
    for (auto& [oldNode, newNode] : mp) {
        if (oldNode->next) {
            newNode->next = mp[oldNode->next];
        }
    }

    return mp[head];
}
```

### 双向链表

节点有 `prev` 和 `next`，深拷贝时两个指针都要指向新节点：

```text
原：A <-> B <-> C
新：A' <-> B' <-> C'
```

复制时：

- `newNode->next = 下一个新节点`
- `newNode->prev = 上一个新节点`

不能直接复制旧 `prev` / `next` 地址。

## 2.7 重点注意事项

- 不要复制指针的值，而是复制指针指向的对象，并让新指针指向新对象。
- 对于链表 `next`：遍历原链表；对每个原节点 `new` 一个新节点；只复制数据成员；把新节点的 `next` 指向下一个新节点；不要直接复制原节点的 `next` 地址；不要依赖含指针节点的默认拷贝构造；析构时遍历新链表，逐个 `delete`；拷贝赋值用 copy-and-swap 保证异常安全和自赋值安全。
- 空链表必须判断，否则解引用空指针崩溃。
- 如果 `N` 的 `next` 未初始化，最后必须设置 `curr->next = nullptr;`。
- 异常安全：如果循环中 `new` 抛异常，前面已分配的节点会泄漏。工程上推荐用 `std::unique_ptr` 管理节点，或用 copy-and-swap。
- 如果有环，会死循环，需要用哈希表。
