`setpgid(0, 0)` 的作用是：

**把当前进程放入一个新的进程组，并让当前进程成为该进程组的组长，新的进程组 ID 等于当前进程的 PID。**

等价于：

```c
setpgid(getpid(), getpid());
```

参数含义：

- 第一个 `0`：表示操作对象是**当前进程**。
- 第二个 `0`：表示把进程组 ID 设置为该进程自己的 PID。

成功后的效果：

- 当前进程的 `PGID` 变成它自己的 `PID`；
- 当前进程从原来的进程组中移出，进入一个新的进程组；
- 可以用 `kill(-pgid, sig)` 向这个新进程组发信号；
- 在终端作业控制中，它会被当作一个独立的进程组/作业。

常见用途：  
`fork()` 后让子进程独立成一个进程组，例如：

```c
if (fork() == 0) {
    setpgid(0, 0);
    // 子进程成为新进程组组长
}
```

注意：

- 如果当前进程已经是进程组组长，`setpgid(0, 0)` 会失败，`errno = EPERM`。
- 它**不会创建新会话**，也不会脱离控制终端。要创建新会话应使用 `setsid()`。
- `setpgid` 只改变进程组，不改变父子关系。
