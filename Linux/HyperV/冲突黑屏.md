 三、如果点 OK 后黑屏几秒又弹回登录框（最可能的情况）

 根据 Ubuntu 官方测试文档（Canonical Hyper-V 镜像的测试指引原文）：

 │ Do not select 'Log in automatically' when creating a user, this will break enhanced session.

 你在向导里勾了"自动登录"，所以本机控制台上已经有一个 zhm 的 GNOME 会话在跑（还是 Wayland）。xrdp 再给同一个用户开第二
 个会话时就会互相抢座位/抢 D-Bus/keyring，典型症状就是：黑屏 → 弹回 xrdp 登录框 → 再输还是弹回来；或者卡在蓝绿色背景不
 动。

 ### 修复（在"基本会话"里做，不要在失败的增强会话里做）

 怎么回到基本会话（1024×768 那个桌面）：
 - 虚拟机连接窗口菜单 → 「查看(V)」→ 取消勾选「增强会话」，几秒后就会切回基本会话的控制台桌面；或者关掉窗口重新「连接」
   时不要走增强会话。
 - 也可以用 SSH（你手册里装过 openssh-server）：基本会话里执行 hostname -I 拿到 IP，然后从 Windows ssh zhm@<IP>。

 进去后 Ctrl+Alt+T 开终端，整段粘贴执行：

 ```bash
   # 1) 关掉"自动登录"，同时关掉 Wayland（xrdp 需要 X11 会话）
   sudo sed -i 's/^AutomaticLoginEnable=.*/AutomaticLoginEnable=false/' /etc/gdm3/custom.conf
   sudo sed -i '/^AutomaticLogin=/d' /etc/gdm3/custom.conf
   sudo sed -i 's/^#\?WaylandEnable=.*/WaylandEnable=false/' /etc/gdm3/custom.conf
   grep -nE 'AutomaticLogin|Wayland|InitialSetup' /etc/gdm3/custom.conf
   #   期望：能且只能看到 WaylandEnable=false（以及 InitialSetupEnable=false），不再有 AutomaticLogin*

   # 2) 重设一个你 100% 记得住、无大小写/布局歧义的密码（顺便也能排除密码错的可能）
   sudo passwd zhm

   # 3) 确认家目录属主正常（oem-config 装的系统偶尔会歪）
   id zhm; ls -ld /home/zhm /home/zhm/.Xauthority 2>/dev/null

   # 4) 重启，让本机那个"自动登录的旧会话"彻底消失
   sudo reboot
 ```

 重启后：本机控制台会停在 GDM 登录界面（不再自动登录），系统里没有 zhm 的活动会话了。这时再切回增强会话（「查看」→ 勾选
 「增强会话」），输入 zhm + 刚重设的密码 —— 通常一次就进。

 24.04 常见的黑屏/掉回登录界面 PAM 修复块（来自 Ubuntu 社区在 24.04 上验证过的 xrdp 配置）：

 ```bash
   sudo cp /etc/pam.d/xrdp-sesman /etc/pam.d/xrdp-sesman.bak
   sudo tee /etc/pam.d/xrdp-sesman >/dev/null <<'EOF'
   #%PAM-1.0
   auth       required     pam_env.so readenv=1
   auth       required     pam_env.so readenv=1 envfile=/etc/default/locale
   @include common-auth
   -auth      optional     pam_gnome_keyring.so
   -auth      optional     pam_kwallet5.so

   @include common-account
   @include common-password

   session    required     pam_limits.so
   session    required     pam_loginuid.so
   session    optional     pam_lastlog.so quiet
   @include common-session
   -session   optional     pam_gnome_keyring.so auto_start
   -session   optional     pam_kwallet5.so auto_start
   EOF
   sudo systemctl restart xrdp xrdp-sesman
 ```

 （想还原：sudo cp /etc/pam.d/xrdp-sesman.bak /etc/pam.d/xrdp-sesman）

 最后兜底：Xorg 后端彻底不行时换 Xvnc 后端（此时 Session 下拉框要选 Xvnc，不是 Xorg）：

 ```bash
   sudo apt install -y tigervnc-standalone-server tigervnc-xorg-extension
   sudo systemctl restart xrdp xrdp-sesman
 ```
