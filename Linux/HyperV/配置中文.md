 一、为什么"设好中文 → 退出再连接 → 又变英文"

 两层原因，叠在一起：

 第 1 层：你的增强会话根本不经过 GDM。
 GNOME「设置 → 系统 → 区域与语言」改的语言，是写到 AccountsService（/var/lib/AccountsService/users/zhm 的 Language=）里
 ，只有 GDM 启动图形会话时才会读它。而增强会话是 xrdp-sesman 启动的（不走 GDM），它只认 /etc/default/locale —— Ubuntu
 的 /etc/xrdp/startwm.sh 里就是 . /etc/default/locale; export LANG LANGUAGE。所以你改的设置在本机控制台会话有效，在增强
 会话里"重连即失效"，每次从系统默认值（英文）重新开始。

 第 2 层：这个官方镜像里压根没有中文语言包。
 我核对了它的包清单（...vhdx.zip.manifest），里面只有：

 ```
   language-pack-en      1:24.04+20240419
   language-pack-en-base 1:24.04+20240419
 ```

 没有 language-pack-zh-hans。所以就算把 LANG 设成 zh_CN.UTF-8，界面也没有中文翻译文件可加载 → 还是英文（中文字体倒是有
 ，fonts-noto-cjk 已装，所以中文显示不会乱码）。镜像里装了 ibus/im-config，但没有拼音引擎（ibus-libpinyin 没装）。

 修复（在 Ubuntu 终端执行，一次搞定）

 ```bash
   # 1) 装中文语言包（关键）+ 拼音输入法
   sudo apt update
   sudo apt install -y language-pack-zh-hans language-pack-zh-hans-base language-pack-gnome-zh-hans \
                       fonts-noto-cjk ibus-libpinyin

   # 2) 生成 locale 并确认
   sudo locale-gen zh_CN.UTF-8
   locale -a | grep -i zh_CN

   # 3) 改「系统默认语言」——这才是增强会话读的地方
   sudo tee /etc/default/locale >/dev/null <<'EOF'
   LANG=zh_CN.UTF-8
   LANGUAGE=zh_CN:zh
   EOF

   # 4) 顺手让本机控制台/GDM 会话也是中文（可选，建议）
   sudo sed -i '/^Language=/d' /var/lib/AccountsService/users/zhm 2>/dev/null
   sudo sed -i '/^\[User\]/a Language=zh_CN.UTF-8' /var/lib/AccountsService/users/zhm

   # 5) 确认 xrdp 会加载上面的设置（应能看到 default/locale 那一行）
   grep -n -A3 "default/locale" /etc/xrdp/startwm.sh

   # 6) 输入法环境变量（xrdp 会话会执行 ~/.xsessionrc）
   cat > ~/.xsessionrc <<'EOF'
   export LANG=zh_CN.UTF-8
   export LANGUAGE=zh_CN:zh
   export GTK_IM_MODULE=ibus
   export QT_IM_MODULE=ibus
   export XMODIFIERS=@im=ibus
   ibus-daemon -drx &
   EOF

   sudo reboot          # 或注销后重新连接
 ```

 重连后：界面应为中文；Super+空格（或 Ctrl+空格）切换中英文输入，输入源里应有「中文（智能拼音）」。

 记住这条规矩：以后要改语言，改 /etc/default/locale，不要指望 GNOME 设置里的语言对增强会话生效。
